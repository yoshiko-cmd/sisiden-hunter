# 付録B. 編集ガイドライン

要件13「AIが事実関係を抽出できる明快な文章構造と、人間が物語として読みたくなる文章の両立」を、
実際の執筆ルールに落としたもの。

---

## B-1. 両立の原理

この2つは対立しない。**役割の違うブロックに分ければよい。**

```
┌─────────────────────────────────────────────┐
│ リード（lead）        ← 事実で書く。AIが読む   │
│ 5W1H・固有名詞・取材日・数値                   │
├─────────────────────────────────────────────┤
│ 本文冒頭             ← 情景で書く。人間が読む  │
│ 場面・音・光・表情                            │
├─────────────────────────────────────────────┤
│ 見出し（H2）         ← 問いで書く。両方が読む  │
├─────────────────────────────────────────────┤
│ 本文                 ← 物語で書く             │
│ 証言・場面・時系列                            │
├─────────────────────────────────────────────┤
│ 解説BOX              ← 定義で書く。AIが読む   │
├─────────────────────────────────────────────┤
│ この記事について       ← 事実で書く。AIが読む   │
└─────────────────────────────────────────────┘
```

情緒を捨てる必要はない。**情緒を置く場所を決める**だけ。

---

## B-2. リード文の型

120〜160字。以下の順で書く。

```
1文目: 結論（誰が / 何を / どこで）
2文目: 補足（なぜ / どうやって）
3文目: SISIDENの取材事実（いつ / どこで取材したか）
```

### 例

> TONKANは、横浜市の若者たちが自ら立ち上げた「街の居場所」である。運営の中心にいるのは
> 大学生の小倉莉恩。飲食店の空き時間を借りる形で、2024年から続いている。
> SISIDENは2026年8月、4日間にわたって現場を取材した。

### 禁止

- 「〜ではないだろうか」で終わる（結論を出していない）
- 「ある街に、一軒の店がある」（固有名詞がない）
- 「近年、若者の孤立が問題になっている」（一般論から入る＝AIにとって価値がない）

---

## B-3. 見出しの型

**問いの形にする。**

| × | ○ |
|---|---|
| TONKANの取り組み | なぜ若者たちは、自分たちで居場所をつくったのか |
| 課題と展望 | 続けるために、いま何が足りないのか |
| 小倉さんの思い | 小倉莉恩は、なぜ大学生活の半分をここに使うのか |

AI検索は質問に答える。**見出しが質問文なら、そのセクションがそのまま回答になる。**

---

## B-4. 固有名詞と数値のルール

| ルール | 例 |
|---|---|
| 初出はフルネーム + 肩書き + 所属 | `小倉莉恩（おぐら・りおん）／大学生、TONKAN運営メンバー` |
| 2回目以降も「小倉」と姓で書く | 「彼女」で受けない |
| 組織は正式名称を初出で | `株式会社シシクリエイション（東京都港区）` |
| 地名は都道府県から | `神奈川県横浜市` |
| 日付は年から | `2026年8月12日`。「先日」「昨年」を使わない |
| 数値は具体的に | 「多くの若者」→「週におよそ40人」 |
| 出典は文中に | 「〜と言われている」→「国土交通省の2025年度調査によれば」 |

## B-5. 引用（証言）の扱い

SISIDENの記事の主役は**本人の言葉**である。

- 引用は**要約しない**。言い淀みや反復も、意味があるなら残す
- 引用の直後に「つまり〜ということだ」と解説を足さない（読者を信用する）
- 話者名と、可能なら取材日を添える
- **1記事に最低3つの引用**を入れる。ないなら取材が足りていない

```
「居場所って、つくれるんだと思ったんです。誰かが用意してくれるのを
 待つんじゃなくて」
                                    ─ 小倉莉恩（2026年8月12日）
```

## B-6. 解説BOXの型

用語・制度・業界構造を、本文の流れを止めずに説明する。
**AI検索が独立した意味単位として抽出しやすい。**

```
┌─ 解説 ─────────────────────────────────┐
│ 地域おこし協力隊                          │
│ 総務省が2009年に開始した制度。都市部の住民が │
│ 過疎地域に移住し、最長3年間、地域活動に従事 │
│ する。2024年度の隊員数は約7,200人。        │
│ （出典: 総務省「地域おこし協力隊の概要」）    │
└──────────────────────────────────────┘
```

型: `用語名 → 定義1文 → 補足1〜2文 → 出典`
100〜200字。これ以上長くなるならISSUEページに分離する。

## B-7. 記事カテゴリ別の書き方

| カテゴリ | 主語 | 文体 | 分量 | 注意 |
|---|---|---|---|---|
| 01 証言 | 本人 | 一人称の語りを中心に、地の文は最小限 | 3,000〜6,000字 | 編集が語りすぎない |
| 02 取材ノート | 制作者 | 一人称。主観を出してよい | 2,000〜4,000字 | **唯一、主観が許されるカテゴリ**。ただし取材対象を評価しない |
| 03 社会の構造 | なし（三人称） | 客観・データ中心 | 3,000〜5,000字 | 必ず1次ソースを引く。SISIDENの取材内容と統計を接続する |
| 04 地域の文脈 | なし | 客観 | 2,000〜4,000字 | 地域を「課題の集合」として書かない。歴史と産業から入る |
| 05 洞察 | 専門家 | 対話または寄稿 | 2,000〜4,000字 | 肩書き・所属・専門分野を明記。PEOPLEに登録する |
| 06 その後 | 本人 / 制作者 | 報告 | 1,500〜3,000字 | 変化があった事実のみ書く。成果を誇張しない |

## B-8. 倫理・取材ポリシー（公開ページにも掲載する）

`/sisiden/about/reporting-policy/` に掲載する内容。

1. **取材対象者に、記事化と人物ページ作成の同意を得る**
   映像出演の同意とは別に確認する
2. **公開前に、本人に事実確認の機会を提供する**
   ただし編集権はSISIDENが持つ
3. **企業協働作品は、その旨をページ上に明示する**（`client` プロパティ）
4. **取材対象者から削除依頼があった場合の手続きを公開する**
5. **AIによる本文の自動生成は行わない**
   取材記録の文字起こし・構成補助への利用は可とし、その旨を明記する
6. **ストックフォトを使わない**。現場で撮った写真のみを使う
7. **統計は1次ソースにあたる**。まとめ記事を出典にしない

このポリシーページ自体が、E-E-A-TとAI検索における信頼シグナルになる。
**形式的に置くのではなく、実際に守れる内容だけを書く。**
