# STEP 9. デザインシステム

## 9-1. デザイン原則

| # | 原則 | 具体 |
|---|---|---|
| 1 | **写真・人物・言葉を大きく扱う** | 画像は原則フルブリードか大サイズ。小さなサムネイルの羅列を作らない |
| 2 | **余白が情報である** | セクション間 120〜200px。詰め込むと「企業サイト」になる |
| 3 | **装飾しない** | 影・グラデーション・角丸・アイコンを原則使わない。要素は罫線と余白で分ける |
| 4 | **色数を増やさない** | 黒・白・グレー + アクセント1色。カテゴリごとの色分けをしない |
| 5 | **文字で語る** | バッジ・ピル・タグUIを多用しない。英大文字のラベルと罫線で階層を作る |
| 6 | **2つのモードを持つ** | 「CINEMA（作品・HERO）＝黒」と「PAPER（読む）＝生成り」を明確に切り替える |

### 避けるべき表現（企業オウンドメディア化の兆候）

```
× カードに影と角丸              × カテゴリごとのカラーバッジ
× 「詳しくはこちら」ボタン        × 記事末尾の問い合わせCTA
× アイコン付きの3カラム訴求       × 実績ロゴの横並び
× グラデーションのヒーロー背景     × 吹き出し・マーカー装飾
```

## 9-2. カラートークン

```
── CINEMA（作品ページHERO・トップHERO・フッター）───────────────
--sisiden-black        #0A0A0A    背景
--sisiden-black-soft   #141414    カード背景
--on-black-primary     #FFFFFF    見出し
--on-black-secondary   rgba(255,255,255,0.64)   本文・メタ
--on-black-tertiary    rgba(255,255,255,0.38)   補助・罫線上の文字
--rule-on-black        rgba(255,255,255,0.14)   罫線

── PAPER（記事本文・一覧・人物・課題）────────────────────────
--sisiden-paper        #FAF9F7    背景（純白ではなく生成り）
--sisiden-paper-alt    #F2F0EC    セクション区切りの背景
--ink-primary          #14120F    本文・見出し
--ink-secondary        #5A554E    メタ情報
--ink-tertiary         #8F8A82    補助
--rule-on-paper        rgba(20,18,15,0.12)   罫線

── ACCENT（1色のみ）────────────────────────────────────
--sisiden-accent       #B5452F    ホバー・現在地・重要導線
                                  （錆色／土の赤。ドキュメンタリーの
                                    現場性と相性がよく、彩度が低いため
                                    写真の邪魔をしない）
--sisiden-accent-weak  rgba(181,69,47,0.10)   ハイライト背景
```

### 色の使用ルール

- アクセント色は**1画面に3箇所まで**
- カテゴリを色で分けない（`01 証言` のような番号+文字で分ける）
- 写真の上に載せる文字は白のみ。色文字を写真に重ねない
- 黒背景⇄生成り背景の切り替えは**セクション単位**で行い、中間色を挟まない

## 9-3. タイポグラフィ

### 書体

| 用途 | 書体 | 備考 |
|---|---|---|
| 日本語 見出し | **Zen Old Mincho** または **Shippori Mincho** | 明朝。ドキュメンタリー/雑誌の質感 |
| 日本語 本文 | **Noto Sans JP**（Light / Regular） | 長文の可読性を優先しゴシック |
| 欧文 見出し・ラベル | **Inter** または **Archivo** | 英大文字のラベル用。字間を広げる |
| 数字・日付 | 欧文書体を適用 | 日本語書体の数字は字形が揃わない |

**【要確認】** STUDIOのフォント一覧に上記が含まれるか。
含まれない場合の代替:

| 第1候補 | 代替1 | 代替2 |
|---|---|---|
| Zen Old Mincho | Shippori Mincho | Noto Serif JP |
| Noto Sans JP | Zen Kaku Gothic New | 游ゴシック体 |
| Inter | Archivo | Helvetica Neue / Arial |

**見出しを明朝、本文をゴシック**という組み合わせだけは守る。
これが「ドキュメンタリー雑誌」の質感を最も安く実現する。

### タイプスケール

| トークン | Desktop | Mobile | 用途 | 字間 | 行間 |
|---|---|---|---|---|---|
| `display` | 88px | 44px | トップHERO「SISIDEN」 | 0.08em | 1.1 |
| `h1` | 56px | 32px | 作品タイトル / 記事タイトル / 課題の問い | 0.02em | 1.35 |
| `h2` | 32px | 24px | セクション見出し・本文の大見出し | 0.02em | 1.5 |
| `h3` | 22px | 18px | 本文の小見出し | 0.02em | 1.6 |
| `lead` | 20px | 17px | リード文 | 0.03em | 1.9 |
| `body` | 17px | 16px | 本文 | 0.04em | **2.0** |
| `quote` | 28px | 20px | 引用・証言 | 0.02em | 1.8 |
| `meta` | 13px | 12px | 取材日・クレジット | 0.06em | 1.7 |
| `label` | 12px | 11px | `DOCUMENTARIES` 等の英ラベル | **0.16em** | 1.0 |

### 日本語組版で必ず守ること

- **本文の行間は 2.0**。1.6では雑誌に見えない
- **本文幅は 680px（1行 38〜42字）**。これを超えると読み疲れる
- 字間 `letter-spacing: 0.04em`。日本語は少し開けると上質に見える
- 英大文字ラベルは字間 `0.16em`（これだけで「編集メディア」の顔になる）
- 見出しの折り返し位置を意識する（STUDIOでは改行を手動で入れて調整可）

## 9-5. コンポーネント定義

### セクション見出し

```
DOCUMENTARIES                                        VIEW ALL →
───────────────────────────────────────────────────────────
```
- 英大文字 `label` サイズ・字間0.16em
- 右端に導線。下に1px罫線
- 日本語の副題を付ける場合は `── 作品一覧` と罫線接頭辞で

### 作品カード（ポスター型）

```
┌────────────┐
│            │   画像 3:4
│  [image]   │   ホバー: 1.03倍スケール（0.6s ease）+ 明度わずかに上げる
│            │   ※ 影・角丸なし
├────────────┤
│ TONKAN     │   h3 / 明朝
│ 若者がつくった…│   meta / ink-secondary
│ 横浜 · 11:24│   meta / ink-tertiary
└────────────┘
```

### 記事カード（横長リスト型）

```
┌──────────┐  01 証言 ／ TONKAN            ← label + accent
│ [16:9]   │  「居場所って、つくれるんだと思った」  ← h3 明朝
└──────────┘  リード1行省略                  ← body / ink-secondary
              2026.09.20 ／ 取材・文 ◯◯◯     ← meta
──────────────────────────────────────────  ← 1px罫線で区切る
```

**カードを箱で囲まない。**罫線で区切るだけにする。これが雑誌の誌面に近づく。

### 引用ブロック（記事の主役）

```
        ┏━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┓
          「 居場所って、つくれるんだと
            思ったんです。 」
                            ─ 小倉 莉恩
        ┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛
```
- `quote` サイズ（28px）・明朝
- 本文幅より**左右に32pxはみ出す**（本文の流れを視覚的に断ち切る）
- 上下に罫線または大きな余白。背景色は付けない
- 話者名は `meta` サイズで右寄せ

### 解説BOX

```
┌─ 解説 ─────────────────────────────┐
│ 用語や制度の説明。100〜200字。        │
└──────────────────────────────────┘
```
- 背景 `--sisiden-paper-alt`、罫線1px、角丸なし
- 見出しは `label` サイズで `解説`
- **AI検索が抽出しやすい独立した意味単位**として機能する

### 人物チップ（丸ポートレート）

```
 ( ○ )
 小倉 莉恩
 大学生 / TONKAN
```
- 円形 96px（Desktop）/ 72px（Mobile）
- ホバーでアクセント色の細いリング

### 「この物語を映像で見る」ブロック（記事末尾・最重要）

```
─────────  この物語を映像で見る  ─────────

┌──────────────────────────────────────┐
│                                      │  黒背景（CINEMAモードに切替）
│        [ key_visual 16:9 ]   ▶       │  中央に再生アイコン
│                                      │
│  TONKAN                              │
│  若者がつくった、街の居場所。            │
│                    WATCH DOCUMENTARY →│
└──────────────────────────────────────┘
```
**ここだけ記事の中でモードが黒に切り替わる。**
読む体験から観る体験への転換を、色で表現する。

### メタ情報ブロック（この記事について）

```
┌────────────────────────────────────────────┐
│  この記事について                             │
│  この記事は、SISIDENが横浜市で2026年8月12日に   │
│  行った取材をもとに制作しています。              │
│  取材対象  小倉莉恩（TONKAN）ほか2名           │
│  取材・文  ◯◯◯  ／  撮影  ◯◯◯              │
│  公開 2026.09.20  ／  更新 2026.09.20        │
└────────────────────────────────────────────┘
```
- `meta` サイズ・罫線囲み・背景なし
- **全記事に必ず配置**。E-E-A-TとAIOの実装の中核（[STEP 7-2](./07-seo-aio.md)）

## 9-6. 画像規定

| 用途 | 比率 | 最小サイズ | 備考 |
|---|---|---|---|
| 作品キービジュアル | 16:9 | 2400×1350 | 本編からの静止画を使う |
| 作品ポスター（縦） | 3:4 | 1200×1600 | 一覧用。人物の顔が入る構図 |
| 記事ヘッダー | 16:9 | 2000×1125 | |
| 記事内写真 | 自由 | 長辺1600以上 | キャプション必須 |
| ポートレート | 3:4 / 1:1 | 800×1000 | 目線がカメラに向いているもの |
| OGP | 1200×630 | - | 文字を焼き込まない |

### 写真のトーン統一

- 彩度を上げない。**現場の光をそのまま使う**
- 全体に軽くコントラストを落とし、統一感を出す
- ストックフォトを使わない（特にISSUEページ。**取材写真がないなら画像なしで出す**）
- 人物写真は演出しない。取材中のスナップを優先する

## 9-7. モーション

| 要素 | 動き | 時間 |
|---|---|---|
| ページ内スクロール出現 | フェードイン + 16px上昇 | 0.8s ease-out |
| 画像ホバー | 1.03倍スケール | 0.6s ease |
| リンクホバー | 下線がアクセント色で左から伸びる | 0.3s |
| HERO | 画像の極ゆっくりズーム（1.0→1.08） | 20s linear |
| ページ遷移 | フェード | 0.3s |

**原則: 速い動きを使わない。**
ドキュメンタリーの時間感覚をUIでも再現する。バウンス・回転・スライドインは使わない。

## 9-8. STUDIOでの「できる / できない / 代替」

| やりたいこと | STUDIO | 代替 |
|---|---|---|
| カラー・タイポのトークン管理 | ○ **スタイル機能**でテキストスタイル・カラーを登録 | 最初に全トークンを登録してから作り始める |
| レスポンシブのブレークポイント | ○ 4段階（Desktop/Laptop/Tablet/Mobile） | - |
| 日本語Webフォント | ○ 標準フォント一覧から選択 | **【要確認】** 希望書体がなければ9-3の代替表 |
| Adobe Fonts / 外部フォント | △ | カスタムコードで `@font-face` を読み込む（表示速度に注意） |
| スクロール連動アニメーション | ○ モーション機能 | - |
| ホバー時の画像拡大 | ○ | - |
| 引用の本文幅はみ出し | ○ リッチテキストのblockquoteにスタイル適用 | 幅指定が効かない場合は引用を本文幅内に収める |
| 明朝/ゴシックの使い分け | ○ テキストスタイルで管理 | - |
| ダークモード切替 | × | 不要（CINEMA/PAPERはセクション単位で固定） |
| 画像の自動最適化 | ○ STUDIOが自動でWebP配信 | - |

### 実装順序（重要）

STUDIOでは**スタイルを先に定義してから要素を作る**。後から一括変更するのが難しいため。

```
1. カラースタイルを9-2の全トークン分登録
2. テキストスタイルを9-3の全スケール分登録（Desktop値で作り、各ブレークポイントで上書き）
3. スペーシングのルールをチームで共有（8の倍数）
4. コンポーネントを作成し、STUDIOの「コンポーネント」として登録
5. ページ制作開始
```

この順を守らないと、記事が50本を超えたあたりで手戻りが発生する。
