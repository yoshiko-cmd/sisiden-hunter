## 0. 調査の制約

実行環境のネットワークポリシーにより `sisicreation.com` へ直接アクセスできないため、
**実ページのHTML・全ページ一覧・現在のSEO設定は未検証**である。

本書は以下を根拠に組み立てている。

1. STUDIO CMSダッシュボードで確認したモデル構成（実データ）
2. 検索インデックスに露出しているURL
3. 各種プレスリリース・報道から確認できる事業内容
4. B2B映像制作の購買行動と検索市場の一般的構造

精度を上げるために必要な情報は [4-6](#4-6-精度を上げるために必要な情報) に列挙した。

## 1. 最初に決めるべき論点：メディアと営業サイトの同居

SISIDEN MEDIAの設計では「**制作実績サイトに見せない**」ことを最重要条件にした。
一方で今回の要望は「**B2B営業要素を入れたい**」である。

これは矛盾ではない。**同じドメインの中で役割を分ければ両立する。**
むしろ、片方がもう片方を強化する関係にある。

```
┌─────────────────────────────────────────────────────────┐
│ sisicreation.com/                                       │
│                                                         │
│   ■ コーポレート領域（B2B・営業）                          │
│     主語 = 私たち（株式会社シシクリエイション）              │
│     読者 = 発注を検討している企業・自治体の担当者             │
│     目的 = 問い合わせ・提案機会の獲得                       │
│           ↓ 「私たちは本当に現場に行っている」の証明として引用  │
│                                                         │
│   ■ sisicreation.com/sisiden/（編集メディア）              │
│     主語 = 取材対象者（第三者視点）                         │
│     読者 = 社会課題や人物に関心のある一般読者                 │
│     目的 = 一次情報の蓄積・信頼の獲得                       │
│           ↑ 接続はフッターの Produced by SISI CREATION のみ │
└─────────────────────────────────────────────────────────┘
```

### なぜこの関係が有効か

B2Bで映像制作を発注する担当者が本当に知りたいのは、価格でも機材でもない。

> **この会社は、うちの現場にちゃんと入り込んでくれるのか**

SISIDEN MEDIAは、それに対する**最も強い証拠**になる。
取材日・取材地・当事者の言葉が記録された記事が100本あることは、
「密着取材が得意です」という営業文句の1,000倍説得力がある。

したがって導線は**一方向**にする。

| 方向 | 可否 | 理由 |
|---|---|---|
| コーポレート → SISIDEN | **強く出す** | 実績・本気度の証明。営業資料としても使える |
| SISIDEN → コーポレート | フッター1行のみ | 編集メディアの独立性を守る。ここを崩すと記事の信頼が落ちる |

**SISIDEN内に「制作のご依頼はこちら」を置かない。** これは守る。

## 2. CMSから読み取れる現状構造

STUDIO CMSのモデル構成から、現在のサイトはおおよそ以下と推定される。

| モデル | 件数 | 対応するページ群 | 推定 |
|---|---|---|---|
| 新着記事 | 20 | お知らせ / ニュース | プレスリリース・作品公開告知が中心 |
| 記事 | 3 | ？ | **用途不明。新着記事との重複** |
| 制作事例 | 5 | 制作実績 | **B2B営業の中核。5件は少ない** |
| 制作事例カテゴリー | 4 | 実績の絞り込み | |
| 制作事例-地域カテゴリ | 5 | 地域での絞り込み | 自治体案件を意識した設計 |
| 投稿者 | 1 | 記事の著者 | |
| メンバー | 1 | チーム紹介 | **1名のみ。体制が見えない** |
| 職種 | 5 | 採用 | 採用ページが存在する |

### ここから見える構造上の問題

**① 制作事例が5件しかない**
B2Bサイトで最も見られるのは実績ページ。5件では「実績が少ない会社」に見える。
一方でSISIDENのYouTubeには複数の作品がある。**作品が実績として登録されていない。**

**② 「新着記事」と「記事」が重複している**
どちらに何を入れるかの基準が失われている状態。URL構造も二重化する。

**③ メンバーが1名**
B2B、特に自治体案件では「誰が作るのか」「体制は足りるか」が審査される。
1名表示は、発注側から見ると不安材料になる。

**④ 採用（職種5件）は整備されているが、営業側が薄い**
採用に力が入っている一方、**発注者向けのコンテンツが構造として存在しない**
（サービス紹介・制作フロー・料金・課題別提案などのモデルがない）。

**⑤ Slugが全件ランダム文字列**
`/3JcLQK8w` `/5g0juwaJ` のような自動生成パスが公開・インデックスされている。
制作事例のURLも同様と推定される。**B2B SEOで最も基本的な欠落。**

## 3. SEO上の課題（確度別）

### 確実（実データで確認済み）

| # | 課題 | 影響 |
|---|---|---|
| 1 | CMSアイテムのSlugが全件ランダム | URLにキーワードが入らない。被リンクのアンカーにならない。共有時に内容が伝わらない |
| 2 | 同一記事が公開中と下書きで重複 | 重複コンテンツ。クロールバジェットの無駄 |
| 3 | 記事モデルが2つに分裂 | 情報の分散。内部リンクが組めない |

### 高確度（STUDIOの標準動作と検索結果から推定）

| # | 課題 | 確認方法 |
|---|---|---|
| 4 | メタディスクリプションがページ個別に設定されていない | 検索結果に本文の断片が出ていないか |
| 5 | 構造化データ（Organization / VideoObject）が未設定 | リッチリザルトテストで確認 |
| 6 | 制作事例ページに動画の構造化データがない | 同上。**動画を持つ会社にとって最大の機会損失** |
| 7 | 内部リンク設計がない（実績↔お知らせ↔サービスが繋がっていない） | 各ページの本文内リンク数 |
| 8 | 見出し構造（H1/H2）がデザイン優先で崩れている | ページのアウトライン |
| 9 | 画像のalt属性が未設定 | 画像を右クリック→検証、またはSTUDIOの画像設定 |

### 要確認

| # | 項目 |
|---|---|
| 10 | Google Search Console / GA4 の登録有無 |
| 11 | 会社概要の情報量（資本金・設立・所在地・代表者・従業員数） |
| 12 | プライバシーポリシー・情報セキュリティ方針の有無 |
| 13 | 問い合わせフォームの項目設計 |
| 14 | 表示速度（動画埋め込みが多いサイトは重くなりやすい） |

## 4. 検索戦略：どこで戦い、どこで戦わないか

### 4-1. 戦ってはいけないキーワード

| キーワード | 理由 |
|---|---|
| 動画制作 / 映像制作会社 / 動画制作 東京 | 大手制作会社・比較メディア・広告代理店が占有。数千万円規模のSEO投資が必要 |
| PR動画 / プロモーション動画 | 同上。かつ意図が広すぎて問い合わせ品質が低い |
| 採用動画 制作 | 中激戦。専業サービスが多数 |

**ここを狙うと、労力に対して成果が出ない。**

### 4-2. 勝てるキーワード（SISIDENの固有性が効く）

| クラスタ | キーワード例 | なぜ勝てるか |
|---|---|---|
| **ドキュメンタリー × 法人** | 企業 ドキュメンタリー 制作 / 密着ドキュメンタリー 制作会社 / 社員 密着 動画 | 専業がほとんどいない。SISIDENの実績がそのまま証拠になる |
| **自治体・官公庁** | 自治体 ドキュメンタリー / 地方創生 動画制作 / 移住promotion 映像 / 自治体 プロモーション動画 プロポーザル | 発注者の検索行動が明確。競合が「東京の制作会社」しかいない |
| **課題ドリブン** | 事業承継 動画 / 職人 技術継承 映像 / 建設業 採用 ドキュメンタリー / 災害復興 記録映像 | 検索数は少ないが、**問い合わせ率が桁違いに高い** |
| **指名・周辺** | SISIDEN / シシデン / シシクリエイション | ブランド検索。SISIDEN MEDIAが育つほど増える |

**方針：検索ボリュームではなく、問い合わせ確度で選ぶ。**
月10回検索されて1件受注するキーワードのほうが、
月1,000回検索されて0件のキーワードより価値がある。

### 4-3. B2B購買行動から逆算した必要ページ

映像制作の発注担当者は、おおむねこの順で動く。

```
1. 課題を認識        「採用がうまくいかない」「地域の魅力が伝わらない」
       ↓
2. 手段を探す        「採用 ドキュメンタリー」で検索
       ↓  ← ★課題別サービスページが必要
3. 会社を比較        実績を見る / 費用感を掴む / 体制を確認する
       ↓  ← ★制作実績・料金・制作フロー・チームが必要
4. 信頼を確認        「この会社は本当にできるのか」
       ↓  ← ★SISIDEN MEDIAが効く / 導入企業の声 / 会社概要
5. 問い合わせ        「相談だけでもいいのか」を知りたい
              ← ★問い合わせのハードルを下げる設計が必要
```

現状、**2〜5を支えるページが構造として存在していない**可能性が高い。
制作事例5件だけでは3を支えきれない。

### 4-4. 自治体・官公庁向けの特殊要件

このリポジトリ（sisiden-hunter）が自治体案件を収集している以上、
**入札・プロポーザルは主要な受注経路**である。
その場合、サイトは「検索対策」ではなく「審査対策」として機能する。

公募・プロポーザルの審査で実際に見られる項目：

| 審査項目 | サイト側で必要なもの |
|---|---|
| 会社の実在性・規模 | 会社概要（設立年・資本金・従業員数・所在地・代表者） |
| 同種業務の実績 | **発注機関名・年度・業務名が明記された実績一覧** |
| 実施体制 | メンバー紹介（役割・経験年数）※現在1名 |
| 情報管理体制 | プライバシーポリシー・情報セキュリティ方針 |
| 制作プロセス | 制作フロー・スケジュール例 |
| 成果物の質 | 実際の映像へのリンク（SISIDEN） |

**提案書を読んだ担当者は、必ずサイトを見に来る。**
このときサイトが弱いと、提案書の内容まで割り引かれる。
逆にここが整っていると、提案書を補強してくれる。

→ **B2B施策の中で、自治体向けの整備が最も費用対効果が高い。**
検索順位を上げなくても、既に発生している商談の勝率が上がるため。

### 4-5. AIO（AI検索）における法人向けの機会

「東京 ドキュメンタリー制作会社 おすすめ」のような問いに、
ChatGPTやPerplexityが答える場面が増えている。
AIが引用するのは、**事実が構造化されて書かれているページ**。

- 会社概要が箇条書きで明記されている
- 実績が「発注者・年度・内容」の形で並んでいる
- サービス内容が「誰の・どんな課題を・どう解決するか」で書かれている

これは4-4の自治体向け整備とほぼ同じ作業になる。**一石二鳥。**

### 4-6. 精度を上げるために必要な情報

以下があれば、推定を確定に変えられる。

| # | 必要なもの | 取得方法 |
|---|---|---|
| 1 | **全ページ一覧とパス** | STUDIOエディタ > ページ一覧 のスクリーンショット |
| 2 | Google Search Console の検索クエリ上位30 | GSC > 検索結果 > クエリ（過去3ヶ月） |
| 3 | GA4 の流入経路とランディングページ上位10 | GA4 |
| 4 | 現在の問い合わせ件数と、その流入元 | ヒアリング |
| 5 | 受注済み案件の一覧（企業/自治体、年度、内容） | 社内資料 |
| 6 | 1件あたりの制作単価レンジ | 社内 |

**1と2があれば、このドキュメントの精度は大きく上がる。**
特に2は「既に何で見つけられているか」が分かるため、戦略の当たり外れが即座に判明する。
