# STUDIO 改修チェックリスト（優先度順）

「効果が出るまでの速さ × 作業量」で並べている。上から順に着手する。

凡例: 影響 ★★★ = 受注に直結 / 工数 = おおよその作業時間

---

## P0. 今週やる（後戻りを防ぐ・すぐ効く）

### ☐ 0-1. Slug運用ルールの確定 　影響★★★ 　工数 5分

**今後作るすべてのCMSアイテムで、Slugを手入力する。**
これを決めないまま進むと、直せない負債が毎日増える。

```
STUDIOの操作: なし（運用ルールの共有のみ）
```

命名規則は [SISIDEN側の早見表](../sisiden-media/11-cms-quickstart.md) と同じ考え方。
コーポレート側は:

| モデル | 規則 | 例 |
|---|---|---|
| 制作事例 | `{発注者}-{内容}` | `shinwa-kensetsu-recruit` |
| 新着記事 | `{内容}-{年月}` | `tetsu-wo-tsugumono-release` |
| 職種 | 職種名の英語 | `director` `editor` |

### ☐ 0-2. 既存Slugを直すかの判断 　影響★★ 　工数 30分

既存の `/3JcLQK8w` などを変更すると、**STUDIOは自動リダイレクトを張らないため404になる。**
一律で直してはいけない。GSCで判断する。

```
Google Search Console > 検索結果 > ページ
  → 各URLの表示回数・クリック数を確認

表示回数がほぼ0        → 変更してよい（失うものがない）
クリックがある / 被リンクあり → 変更しない（そのまま残す）
```

**GSCが未登録なら、まず登録して1ヶ月データを貯めてから判断する。**
それまでは既存URLに触らない。

### ☐ 0-3. 重複アイテムの削除 　影響★ 　工数 10分

同一内容が「公開中」と「下書き」で二重に存在しているものがある
（マンション管理の記事 `UDNbxh6J` / `gOQ4npEM`）。

```
STUDIOの操作: CMS > 新着記事 > 下書きの重複アイテムを削除
```

今後は**アイテムを複製して修正しない**。既存アイテムを直接編集する。

### ☐ 0-4. 「記事」モデル（3件）の用途を決める 　影響★★ 　工数 20分

「新着記事」(20件) と「記事」(3件) が併存している。どちらかに寄せる。

| 判断 | 対応 |
|---|---|
| 同じ用途だった | 3件を「新着記事」に移し、「記事」モデルは削除 → **モデル枠が1つ空く** |
| 違う用途だった | それぞれの役割をドキュメント化し、名前を変えて区別を明確にする |

**モデル枠が1つ空けば、SISIDEN側の予備が2枠になる。**

### ☐ 0-5. 公開済み作品を制作事例に全件登録 　影響★★★ 　工数 2〜3時間

現在5件。YouTubeに公開済みの作品はそれ以上あるはず。

```
STUDIOの操作: CMS > 制作事例 > 新規追加 を繰り返す
```

**B2Bサイトで最も見られるのは実績ページ。5件と15件では信頼度が違う。**
この時点では既存のプロパティのままでよい（拡張はP1）。
Slugだけは必ず手入力する。

### ☐ 0-6. 会社概要に情報を追加 　影響★★★ 　工数 30分

入札の審査項目であり、AI検索が事実として抽出する部分でもある。

```
追加する: 設立年月 / 資本金 / 従業員数 / 代表者名 / 所在地（郵便番号から）
         事業内容（箇条書き）/ 適格請求書発行事業者登録番号
```

```
STUDIOの操作: 会社概要ページを編集（静的ページ）
```

### ☐ 0-7. メンバーを増やす 　影響★★ 　工数 1時間

現在1名。**最低3名。**外部パートナーは「制作パートナー」として区別して記載。

```
STUDIOの操作: CMS > メンバー > 新規追加
```

### ☐ 0-8. Google Search Console / GA4 の登録確認 　影響★★★ 　工数 30分

未登録なら即登録。**これがないと、以降の施策の効果が一切測れない。**

```
STUDIOの操作: プロジェクト設定 > カスタムコード > head に認証タグ・GA4タグを設置
```

## P1. 1ヶ月以内（受注に直結する）

### ☐ 1-1. `/government/` 自治体・官公庁向けページを新設 　影響★★★ 　工数 1日

**最優先。** 検索順位を待たずに、既に発生している商談の勝率が上がる。

構成は [02-site-structure-and-b2b.md](./02-site-structure-and-b2b.md) の4章。

```
STUDIOの操作:
  1. 新規ページ作成 → パスを /government に設定（作成直後に設定する）
  2. 実績表・体制・スケジュール・情報管理・会社概要抜粋 を配置
  3. SEO設定（タイトル・ディスクリプション）
```

実績表には**発注機関名・年度・業務名**を明記する。
公開できない案件は「非公開案件◯件」と件数だけでも書く。

### ☐ 1-2. 制作事例を「ケーススタディ」に作り替える 　影響★★★ 　工数 2日

既存の「制作事例」モデルにプロパティを追加する（新規モデルは作らない）。

```
STUDIOの操作: CMS > 制作事例 > モデル設定 > プロパティを追加
```

| プロパティ名 | タイプ |
|---|---|
| `client_name` | テキスト |
| `client_type` | セレクト（企業 / 自治体 / 業界団体 / 教育機関） |
| `year` | テキスト |
| `challenge` | テキスト |
| `approach` | テキスト |
| `result` | テキスト |
| `client_voice` | テキスト |
| `shoot_period` | テキスト |
| `service_category` | マルチセレクト（採用 / ブランディング / 地方創生 / 事業承継 / 記録） |
| `sisiden_url` | テキスト |

その後、詳細ページのレイアウトを **課題 → したこと → 成果 → 担当者の声** の順に組み替える。

> **STUDIOでできないこと**: 既存アイテムへの一括入力。
> **代替**: 5件（P0後は15件程度）を手で埋める。件数が少ないうちにやるのが正解。

### ☐ 1-3. サービスページを2枚作る 　影響★★★ 　工数 1日

まず `/service/recruit/`（採用ドキュメンタリー）と `/service/local/`（自治体・地方創生）。
検索意図が明確で、既存実績とも合致している2つ。

```
STUDIOの操作: 新規ページ ×2 → パス設定 → 本文作成 → 制作事例のCMSリストを絞り込み配置
```

各ページに **その課題に合致する事例だけ**を表示する。
`service_category` でフィルターをかける（1-2のプロパティ追加が前提）。

### ☐ 1-4. お問い合わせ導線を3段階にする 　影響★★★ 　工数 半日

```
資料ダウンロード  →  オンライン相談（30分・無料）  →  お見積もり
```

自治体向けには「**参考見積のご依頼**」「**公募情報のご連絡**」を追加。
参考見積を明示している制作会社は少なく、差別化になる。

```
STUDIOの操作: フォームを編集 / 各ページ下部にCTAを配置
必須項目は5つまで（会社名・氏名・メール・相談内容・種別）
```

### ☐ 1-5. 全ページのメタディスクリプションを設定 　影響★★ 　工数 2時間

```
STUDIOの操作: 各ページ > ページ設定 > SEO
  タイトル（32字以内）/ ディスクリプション（120字前後）/ OGP画像
```

CMS詳細ページはプロパティを接続して自動生成にする。

### ☐ 1-6. Organization の構造化データを設置 　影響★★ 　工数 1時間

AI検索に会社の事実を伝える。

```
STUDIOの操作: プロジェクト設定 > カスタムコード > head にJSON-LDを貼る
```

コードは [SISIDEN側の 8-2](../sisiden-media/08-structured-data.md) を、
SISIDENではなく**株式会社シシクリエイション**として書き換えたものを使う。

動画を持つ会社にとって最大の機会損失を埋める。

> `duration` は `PT11M24S` 形式が必要。表示用とは別に

### ☐ 2-4. サービスページ残り2枚 　影響★★ 　工数 1日

`/service/documentary/` `/service/branding/`

### ☐ 2-5. 内部リンクの整備 　影響★★ 　工数 半日

現状、実績・お知らせ・サービスが相互に繋がっていない可能性が高い。

```
サービス → 該当する事例
```

### ☐ 2-7. 既存Slugの移行判断を実行 　影響★ 　工数 1時間

0-2でGSCデータが1ヶ月分たまったら判断する。流入のないURLのみ整理。

## 効果が出る順序のイメージ

```
P0完了時点（1週間）
  → 実績15件・会社情報充実・計測開始
  → 提案時にサイトを見られても恥ずかしくない状態

P1完了時点（1ヶ月）
  → /government/ とケーススタディが揃う
  → 既に発生している商談の勝率が上がる  ← ここが最初の成果
  → 問い合わせの質が変わる

P2完了時点（3ヶ月）
  → 検索からの流入が増え始める
  → SISIDEN MEDIAの記事が増え、指名検索が発生し始める
```

**検索順位を狙う施策（P2）より、商談の勝率を上げる施策（P1）を先にやる。**
SEOは半年かかるが、勝率改善は翌週から効く。

## STUDIOでできる / 難しい / 代替

| やりたいこと | STUDIO | 代替 |
|---|---|---|
| 静的ページの追加 | ◎ | - |
| 既存モデルへのプロパティ追加 | ◎ | - |
| 事例の絞り込み表示 | ◎ 複合フィルター対応 | - |
| メタ情報・OGPの個別設定 | ◎ | - |
| JSON-LD | ○ ページ設定またはカスタムコード | - |
| 資料DL（PDF配布 + メール取得） | △ フォームはあるが、フォーム送信後の自動配信は要確認 | フォーム送信 → サンクスページでDLリンクを表示 |
| 301リダイレクト | **要確認** | パスを変更しない設計にする |
| CMSの一括編集 | × | 件数が少ないうちに手作業で済ませる |
| サイト内検索 | × | カテゴリ絞り込みで代替 |
| A/Bテスト | × | 期間を分けて比較 |
