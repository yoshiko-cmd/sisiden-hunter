### CMSモデルへの影響：新規モデルは不要

モデル枠は残り5、SISIDEN MEDIAで3枠使う予定のため、**残り2枠しかない**。
そのためコーポレート側は**新規モデルを作らない**方針とする。

| やりたいこと | 実現方法 | 新規モデル |
|---|---|---|
| サービスページ4種 | 静的ページ4枚 | 不要 |
| 制作実績の強化 | **既存「制作事例」にプロパティを追加** | 不要 |
| 導入企業の声 | 制作事例のプロパティとして持つ | 不要 |
| 自治体向けページ | 静的ページ1枚 | 不要 |
| 制作フロー・料金 | 静的ページ | 不要 |
| メンバー追加 | 既存「メンバー」にアイテム追加 | 不要 |

**残り2枠はSISIDEN MEDIAの `ISSUES` と `AREAS` のために温存する。**

## 2. 最優先：制作実績を「事例」に変える

現在の「制作事例」5件は、おそらく**作品紹介**になっている。
B2Bで効くのは作品紹介ではなく**ケーススタディ**である。

### 違い

```
× 作品紹介
  「◯◯株式会社様の企業紹介映像を制作しました」
  → 読んだ人が自分ごと化できない

○ ケーススタディ
  「若手の応募が集まらない建設会社が、現場監督の1年に密着した。
    公開後、応募数が◯倍に」
  → 同じ課題を持つ担当者が「うちもこれだ」と思う
```

### 「制作事例」モデルに追加するプロパティ

既存モデルを編集して追加する（新規モデルは作らない）。

| プロパティ名 | タイプ | 内容 | 用途 |
|---|---|---|---|
| `client_name` | テキスト | 発注者名（例：進和建設工業株式会社） | 実績証明・入札 |
| `client_type` | セレクト | 企業 / 自治体 / 業界団体 / 教育機関 | 絞り込み |
| `year` | テキスト | `2026`（年度） | 実績証明・入札 |
| `challenge` | テキスト | **課題**：発注前に何に困っていたか | 共感の入口 |
| `approach` | テキスト | **私たちがしたこと**：取材期間・手法 | 差別化 |
| `result` | テキスト | **成果**：公開後に何が起きたか | 意思決定の後押し |
| `client_voice` | テキスト | 担当者の声（引用） | 信頼 |
| `youtube_url` | テキスト | 映像 | 成果物の提示 |
| `duration` | テキスト | 尺 | |
| `shoot_period` | テキスト | 取材期間（例：4ヶ月） | **密着の証明** |
| `service_category` | マルチセレクト | 採用 / ブランディング / 地方創生 / 事業承継 / 記録 | サービスページからの絞り込み |
| `sisiden_url` | テキスト | SISIDEN側の作品ページURL | 深掘り導線 |

### 実績詳細ページの構成

```
┌──────────────────────────────────────────┐
│ [ キービジュアル ]                          │
│ 発注者名 ／ 年度 ／ カテゴリ                  │
│ タイトル（成果が伝わる一文）                   │
├──────────────────────────────────────────┤
│ ▶ 映像（YouTube埋め込み）                    │
├──────────────────────────────────────────┤
│ 課題                                       │
│   発注前に何に困っていたか                     │
├──────────────────────────────────────────┤
│ 私たちがしたこと                              │
│   取材期間◯ヶ月 / 密着日数 / 手法             │
├──────────────────────────────────────────┤
│ 成果                                       │
│   公開後に起きた変化（可能なら数値）             │
├──────────────────────────────────────────┤
│ ご担当者の声                                 │
│   「   」                                   │
├──────────────────────────────────────────┤
│ この物語をもっと読む → SISIDEN MEDIA         │  ★ここでメディアに送る
├──────────────────────────────────────────┤
│ 同じ課題の事例 ／ ご相談はこちら                │
└──────────────────────────────────────────┘
```

**「この物語をもっと読む」でSISIDENに送るのが、2つの領域をつなぐ唯一の正しい導線。**
営業サイトからメディアへは送ってよい（逆は送らない）。

### 件数を増やす

YouTubeに公開済みの作品がすべて実績として登録されていない可能性が高い。
**公開済み作品は全件、実績として登録する。**
5件が15件になるだけで、サイトの説得力は大きく変わる。

## 3. サービスページ（課題別）

「映像制作をします」ではなく「**あなたの課題を解決します**」の構成にする。
検索してくる人は課題で探しているため、課題を見出しにする。

### 共通テンプレート

```
1. 課題の言語化        「若手の応募が来ない」を具体的に描写
2. なぜ従来の手法では届かないか   きれいな会社紹介映像が効かない理由
3. SISIDENのアプローチ  第三者視点・長期密着・当事者の言葉
4. 事例（2〜3件）       制作事例から関連するものを表示
5. 制作の流れ           ヒアリング→企画→取材→編集→納品
6. 費用の目安           レンジで提示
7. よくある質問         3〜5問
8. 相談する             ハードルの低いCTA
```

### 4ページの想定読者

| ページ | 読者 | 検索キーワード |
|---|---|---|
| `/service/documentary/` | 経営者・広報 | 企業 ドキュメンタリー 制作 / 密着 映像 |
| `/service/recruit/` | 人事・採用担当 | 採用 ドキュメンタリー / 社員 密着 動画 |
| `/service/local/` | 自治体・観光協会・地域企業 | 地方創生 動画 / 移住 プロモーション映像 |
| `/service/branding/` | 経営者・マーケ | 企業ブランディング 映像 / 事業承継 記録 |

**まず `/service/recruit/` と `/service/local/` の2枚から作る。**
この2つが最も検索意図が明確で、既存実績とも合致している。

## 4. `/government/` 自治体・官公庁のご担当者へ ★最重要ページ

### なぜ最優先か

公募・プロポーザルで提案書を出すと、**担当者は必ずサイトを見に来る**。
このページは検索順位ではなく、**既に発生している商談の勝率**を上げる。

検索対策の効果は数ヶ月後に出るが、これは**作った翌週から効く**。

### 構成

```
1. 自治体・官公庁のみなさまへ
     地域の課題を、そこで生きる人の物語として記録します

2. 実績
     ┌──────────────────────────────────────┐
     │ 発注機関  │ 年度   │ 業務名          │  ← 表形式で明記
     ├──────────────────────────────────────┤
     │ ◯◯市    │ 2026 │ 移住促進映像制作  │
     └──────────────────────────────────────┘
     ※ 公開可能なもののみ

3. 対応できる業務
     プロモーション映像 / 記録映像 / 移住定住 / 産業振興 /
     災害復興記録 / 教育向け教材 / 議会・行政記録 ほか

4. 実施体制
     ディレクター◯名 / カメラマン◯名 / 編集◯名
     外部協力体制

5. 制作プロセスとスケジュール
     契約 → 企画 → 取材 → 編集 → 検収  の標準スケジュール
     ※ 単年度予算に収まることを明示

6. 情報管理・コンプライアンス
     個人情報の取扱い / 撮影許諾の取得手順 / 素材の管理と納品

7. 会社概要（抜粋）
     商号 / 設立 / 所在地 / 代表者 / 資本金 / 従業員数 / 適格請求書登録番号

8. 公募・プロポーザルのご案内
     「公募情報をお寄せください」
     資料請求 / 見積依頼 / 参考見積の相談
```

### 重要：数字と固有名詞を省略しない

審査担当者は「実績があるか」を**具体名で**確認する。
「多数の自治体様と」ではなく「◯◯市・◯◯町・◯◯県」と書く。
公開できないものは「非公開案件◯件」と件数だけでも出す。

## 5. `/price/` 料金の目安

### 出すべきか

**出す。** B2Bサイトで「料金」は最も検索・クリックされる項目。
出さないと、比較検討の段階で候補から外れる。

ただし単価表ではなく**レンジ + 何が含まれるか**で提示する。

```
┌────────────────────────────────────────────────┐
│ 密着ドキュメンタリー（10分前後）                     │
│ ◯◯万円〜                                        │
│   含まれるもの: 企画 / 取材◯日 / 撮影 / 編集 /      │
│                ナレーション / 楽曲 / 修正2回        │
│   制作期間: 約◯ヶ月                               │
└────────────────────────────────────────────────┘
```

### 効果

- 予算が合わない問い合わせが減る（営業工数の削減）
- 予算が合う相手からの問い合わせが増える（確度の上昇）
- 自治体の積算（予定価格算定）の参考にされ、**発注そのものを促す**

最後の点は特に重要。自治体は「いくらで発注すべきか」の相場が分からず
予算化できないことがある。目安があることで案件が生まれる。

## 6. `/flow/` 制作の流れ

発注者の不安は「何をどこまでやってもらえるのか」「自分たちは何をすればいいのか」。

```
01 ご相談          課題をお聞きします（無料）
02 企画提案        構成案・取材計画・見積
03 ご契約
04 取材・撮影      ◯日〜◯ヶ月。ここがSISIDENの特徴
05 編集            初稿 → ご確認 → 修正
06 納品            データ納品 / YouTube公開支援
07 公開後          効果測定・追加展開のご相談
```

各ステップに「**お客様にお願いすること**」を併記する。
これがあるだけで、発注のハードルが目に見えて下がる。

### 追加すべき情報（入札・AIO両対応）

| 項目 | 理由 |
|---|---|

| 設立年月 | 実在性 |
| 所在地（郵便番号から） | 必須 |

| 資本金 | 審査項目 |
| 従業員数 | 体制の証明 |
| 事業内容（箇条書き） | AIが抽出しやすい |
| 取引先 | 信頼 |

| 加入団体・許認可 | あれば |

### メンバー紹介

現在1名。**最低3名は掲載する。**
外部パートナーを含む場合は「制作パートナー」として区別して記載する。

各メンバーに:
- 氏名 / 役割 / 経歴 / 担当した作品

**SISIDEN MEDIAの `PEOPLE` と役割が似ているが、別物として扱う。**
コーポレート側は「作る人」、SISIDEN側は「登場する人」。混ぜない。

## 8. `/contact/` の導線設計

### 現状の問題（推定）

「お問い合わせ」だけだと、**発注を決めた人しか押さない**。
検討中の9割を取りこぼす。

### 3段階のCTAを用意する

| 温度 | CTA | 想定 |
|---|---|---|
| 低 | **資料をダウンロード**（サービス紹介PDF） | 社内共有したい。名刺代わり |
| 中 | **オンラインで相談**（30分・無料） | 予算も内容も未定。壁打ちしたい |
| 高 | **お見積もり・ご発注** | 要件が固まっている |

自治体向けには追加で:
- **公募情報のご連絡** / **参考見積のご依頼**

参考見積は自治体が予算化のために必要とするもので、
ここを受け付けると明示している制作会社は少ない。**差別化になる。**

### フォームの項目

多すぎると離脱する。**必須は5項目まで。**

```
必須: 会社・団体名 / お名前 / メールアドレス / ご相談内容 / 種別（企業・自治体）
任意: 電話番号 / ご予算 / 希望時期
```
