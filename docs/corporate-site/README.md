## 結論（3行）

1. **コーポレート（営業）とSISIDEN（編集メディア）は役割を分け、導線は一方向にする。**
   コーポレート → SISIDEN は「本気で現場に行っている証拠」として強く出す。逆は出さない。
2. **検索順位より先に、商談の勝率を上げる。**
   `/government/` ページと実績のケーススタディ化は、作った翌週から効く。
3. **「動画制作」では戦わない。**
   「ドキュメンタリー × 法人」「自治体 × 地方創生」「課題ドリブン」の3クラスタで勝つ。

## 最優先の3つ

| 優先 | やること | なぜ |
|---|---|---|
| 1 | 公開済み作品を制作事例に全件登録（現在5件） | B2Bで最も見られるページ。件数が信頼に直結する |
| 2 | `/government/` 自治体・官公庁向けページを新設 | 提案書を出すと必ずサイトを見られる。勝率が直接上がる |
| 3 | 制作事例を「課題 → したこと → 成果」のケーススタディに | 作品紹介では自分ごと化されない |

## 調査の制約

実行環境から `sisicreation.com` にアクセスできないため、
実ページのHTMLと全ページ一覧は未検証。
分析はSTUDIO CMSの実データと検索インデックスの情報に基づく。

精度を上げるために必要な情報は
[01-audit-and-strategy.md の 4-6](./01-audit-and-strategy.md) に列挙した。
