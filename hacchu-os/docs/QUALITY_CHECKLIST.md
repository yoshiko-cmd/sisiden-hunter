# QUALITY_CHECKLIST — 公開前チェック(人が確認する項目)

機械的に確認できるものは `npm run check:content` が行う(✔印)。

- [ ] 検索意図に答えている(想定KWで検索した人が、次の行動を決められるか)
- [x] ✔ 結論が最初にある(summary必須)
- [ ] 競合の言い換えではない(上位3記事と見比べて、この記事にしかない判断基準・テンプレ・一次情報があるか)
- [ ] 一次情報が入っている(✔ 未取得の枠は needsFirsthand で管理)
- [x] ✔ 出典がある(専門家レビュー推奨の記事は sources 必須)
- [ ] 不明な数字を捏造していない(数字ごとに出典か確認日があるか目視)
- [ ] 商品価格が最新か確認している(✔ 未確認の値が残った記事は公開対象にできない)
- [x] ✔ 広告であることを適切に表示している(OfferLink を使う記事は hasAds 必須、PRラベル自動)
- [ ] CTAが検索意図に合っている
- [x] ✔ 内部リンクがある(リンク切れも検出)
- [ ] スマホで読みやすい(390px幅で表・コードが横にはみ出さないか)
- [ ] 誤字脱字
- [ ] 法務・税務の断定表現がない(✔ 代表的な断定表現は警告)
