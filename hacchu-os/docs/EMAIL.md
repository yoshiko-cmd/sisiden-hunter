# EMAIL — メール獲得とステップメール設計

実際の送信は承認後(配信サービスの契約が必要: BLOCKED B-006)。文面・シナリオ・DB設計はここで完成させる。

## リードマグネット

**「外注で失敗しない発注チェックリスト」**(無料・印刷/PDF)
中身はサイトの `/tools/checklist/` と同じ。メール登録者にはPDF版と、記入用のスプレッドシート版を送る。

## 登録導線

| 設置場所 | 文言 | 表示条件 |
|---|---|---|
| 記事の中盤(読者が「抜け漏れ」を気にしたところ) | 発注前チェックリストをPDFで受け取る | 契約・発注・選定カテゴリの記事 |
| 無料ツールの結果画面 | この結果とチェックリストをメールで受け取る | 全ツール |
| フッター | 月1回、外注に使えるテンプレを届けます | 全ページ |

登録項目は**メールアドレスだけ**(任意で「外注したい職種」)。会社名や電話番号は聞かない。

## ステップメール

| 日 | 件名 | 目的 | 本文の骨子 | CTA |
|---|---|---|---|---|
| 0 | 発注前チェックリストをお届けします | 約束の履行 | PDF / スプレッドシートのリンク、使い方3行 | チェックリストを開く |
| 1 | 外注で最初に決めること | 目的・予算・納期・成果物を先に決める | 「誰に頼むか」より先に「何を頼むか」。決めないまま探すと比較できない | 発注内容整理ジェネレーター |
| 3 | 候補者の見極め方 | 面談の質問と評価 | ポートフォリオと仕事の上手さは違う。[運営者一次情報追加予定] | 面談スコアシート |
| 5 | 契約前チェック | フリーランス法の明示事項、修正回数、著作権 | 発注時に書面・メールで明示すべき事項。一般情報であり個別の判断は専門家へ | 電子契約の選び方(PR) |
| 7 | 発注に使うツール | 電子契約・会計・進行管理の最小構成 | 小さな会社で本当に必要なものだけ。表計算で足りる段階の見分け方 | ツール比較ページ(PR) |
| 10 | よくある外注の失敗 | 納期遅延・音信不通・修正地獄 | 失敗の多くは発注時点で防げる。[運営者一次情報追加予定] | 記事: 修正回数で揉めない書き方 |
| 14 | 次に外注するときのために | 継続/終了、評価の記録 | 評価を残すと次の発注が速くなる | 面談スコアシート(評価用) |

以降は月1回のニュースレター(新しいテンプレ・制度変更・読者の質問への回答)。

## DB設計(配信サービスの外に持つ最小限)

```sql
CREATE TABLE subscribers (
  id            INTEGER PRIMARY KEY,
  email         TEXT NOT NULL UNIQUE,
  role_interest TEXT,             -- 外注したい職種(任意)
  source_path   TEXT,             -- 登録したページ
  source_cta    TEXT,             -- どのCTAか(mid-article / tool-result / footer)
  consent_at    TEXT NOT NULL,    -- 同意日時
  consent_text  TEXT NOT NULL,    -- 同意時に表示した文言(版管理)
  status        TEXT NOT NULL DEFAULT 'active',  -- active / unsubscribed / bounced
  unsubscribed_at TEXT
);

CREATE TABLE email_events (
  id            INTEGER PRIMARY KEY,
  subscriber_id INTEGER NOT NULL REFERENCES subscribers(id),
  step          TEXT NOT NULL,    -- d0 / d1 / d3 ...
  event         TEXT NOT NULL,    -- sent / open / click / unsubscribe
  link_id       TEXT,             -- クリック時の offers.json の id
  at            TEXT NOT NULL
);
```

## 法令上の注意(一般情報)

- 広告・宣伝を含むメールは、特定電子メール法の対象になりうる。オプトイン(同意)の記録、送信者情報の表示、
  配信停止の方法の明示を行う(総務省・消費者庁の一次資料を公開前に確認する)。
- 配信サービスは、ダブルオプトインと配信停止リンクに対応しているものを選ぶ。
