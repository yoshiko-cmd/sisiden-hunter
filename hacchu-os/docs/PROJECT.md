# 発注OS(仮称)— PROJECT

> 次回作業開始時は、このファイル → BACKLOG.md → BLOCKED.md → DECISIONS.md の順に確認し、前回の続きから再開する。

## 目的

日本で、フリーランス・業務委託・外注を利用する**発注者**にとって最も実用的なメディアを作り、
SEO・AIO(AI検索)・直接流入・メールから継続的にリードとアフィリエイト収益を生む事業にする。

「フリーランスになる方法」ではなく、**「フリーランスをどう使えば仕事がうまくいくのか」**を
発注者側から一貫して扱う第三者メディア。

```
探す → 比較する → 面談する → 選ぶ → 契約する → 発注する
→ 進行管理する → 納品 → 支払う → 評価する → 継続/終了
```

## ターゲット

従業員1〜50人程度の中小企業・スタートアップの経営者、事業責任者、広報・マーケ担当者。
「社員を採用するほどではない」「でも自分ではできない」「誰に頼めばいいか分からない」人。

## 最大の独自資産

運営者(株式会社シシクリエイション)が実際に多数の外部人材と仕事をしている。
特に映像領域で「約60人面談して、本当に相性が良いと思えた映像制作者は1〜2人程度」という実体験。
→ **最初の実証カテゴリは「映像制作者の選び方」**。そこからデザイン・Web・SNS・広報へ横展開する。

一次情報はヒアリング前に創作しない。未取得箇所は `[運営者一次情報追加予定]` と明記する
(ヒアリング項目は `INTERVIEW_QUESTIONS.md`)。

## 収益モデル(3階層)

1. ASP経由のアフィリエイト(電子契約・会計・クラウドソーシング・SaaS)
2. 各社の公式紹介・リファラルプログラム
3. 直接提携(送客実績ができたらBtoBメディアとして提案)

詳細は `MONETIZATION.md`。

## 優先順位(迷ったとき)

ユーザー価値 > 信頼性 > 収益性 > SEO > 制作の楽さ

コンテンツ優先度: 高い検索意図 > 一次情報 > 収益導線 > リード獲得 > SEO > 記事数
