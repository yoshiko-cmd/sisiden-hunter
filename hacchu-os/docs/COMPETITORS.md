# COMPETITORS — 競合分析(初版)

調査日: 2026-09-23
方法: Web検索の上位結果と各サービスの一般に知られた事業形態からの整理。
**注意**: この環境からは多くのサイトへ直接アクセスできなかった(BLOCKED B-002)。「主な流入キーワード」「強い記事」は
検索上位への出現にもとづく**推定**であり、Ahrefs / Semrush / ラッコキーワード等での実測に置き換えること(BACKLOG)。

## 結論(先に)

1. 検索上位の多くは **受注者(フリーランス)向け** の記事か、**制作「会社」の一括見積・紹介サービス**。
   「個人の外注先(フリーランス)を、発注者がどう選び、どう一緒に仕事をするか」を
   一貫して扱う第三者メディアは見当たらない。
2. 比較・紹介サイトは送客(一括見積・掲載料)が収益源なので、**「会社に頼まない方がいいケース」「頼んだ後の進行管理」**は書かない。
3. 法律メディアは正確だが**発注実務の手順(何をいつ送るか)**に落ちていない。SaaSのオウンドメディアは自社製品に誘導する。
4. つまり空いているのは、**① 選定の実体験(面談・見極め)② 発注〜進行〜支払の実務テンプレ ③ 中立な使い分け(会社/フリーランス/クラウドソーシング/エージェント/知人)**。

## 競合が答えていない質問(記事化候補)

- 「会社」と「フリーランス」と「クラウドソーシング」と「知人紹介」、結局どれに頼めばいいのか(条件別)
- 面談で何を聞けば、ポートフォリオでは分からない「仕事の上手さ」が見えるのか
- ポートフォリオが良いのに一緒に仕事をするとうまくいかないのはなぜか
- 1本目を頼む前に、小さく試す(トライアル)にはどう切り出せばいいか。有償か無償か
- 見積書の金額が3倍違うとき、何を比べればいいか
- 修正回数・修正範囲をどう書けば揉めないか(映像・デザイン別)
- 連絡が途絶えたとき、何日待って何を送るか
- フリーランス法で**発注者が最初の発注メールに書くべきこと**を、メール文面テンプレとして
- 小さな会社で業務委託管理SaaSは必要か(表計算で足りる規模の線引き)
- 継続発注と終了の伝え方
