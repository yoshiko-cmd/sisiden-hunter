## 発注書は「あとで揉めないためのメモ」

発注書というと身構えますが、中身は**何を・いつまでに・いくらで・どうやって**頼むかを、双方が同じ内容で持っておくためのメモです。
フリーランスに仕事を頼む場合は、フリーランス法により、その内容を書面またはメール等で示すことが発注者の義務になっています([フリーランス法の解説](/articles/freelance-act-for-clients/))。

## 必ず書く項目(法律で明示が求められる事項)

| 項目 | 書き方のコツ |
|---|---|
| 発注者・受注者の名称 | 屋号だけでなく、個人名も分かるように |
| 業務委託をした日 | 発注メールを送った日 |
| 仕事の内容 | 相手が読んで、何を納めればいいか迷わない具体さで。「動画制作一式」は避ける |
| 納期(受け取る期日) | 初稿と最終納品を分けて書くと進行管理が楽になる |
| 納品の場所・方法 | 「共有フォルダ」「メール添付」「現地で作業」など |
| 検査(確認)をするなら、その完了日 | 「納品から7日以内に確認」など |
| 報酬の額 | 税込か税抜かを必ず書く |
| 支払期日 | 「◯月◯日」と日付で。受け取りから60日以内 |
| 支払方法(現金以外の場合など) | 振込の場合は振込手数料の負担も書いておくと親切 |

## 書いておくと揉めない項目

法律上の必須事項ではありませんが、トラブルの原因になりやすいので、発注時に決めておくことをおすすめします。

| 項目 | なぜ必要か |
|---|---|
| 目的と、見てもらう相手 | 目的が共有されていないと、修正の往復が増える |
| 修正の回数と範囲 | 「どこまでが修正で、どこからが追加の仕事か」の線を引く([詳しく](/articles/revision-rules/)) |
| 著作権・利用範囲 | 納品後に、別の媒体で使ったり編集したりできるか |
| 制作実績としての公開 | 相手がポートフォリオに載せてよいか、いつからか |
| 経費の扱い | 交通費・素材購入費・機材費が報酬に含まれるか |
| 秘密情報の扱い | 社外秘の情報を渡すなら、NDAや秘密保持の一文を |
| キャンセル時の扱い | 途中で中止する場合、どこまでの作業に支払うか |

## メールで送る場合の文面テンプレート

```text
◯◯ 様

お世話になっております。株式会社△△の□□です。
下記の内容で正式に業務をご依頼いたします。内容をご確認のうえ、お引き受けいただけるかご返信ください。

■ 発注内容
・発注者: 株式会社△△
・受注者: ◯◯(屋号: ◯◯)
・業務委託日: 2026年10月1日
・業務名: 採用サイト用インタビュー動画の制作
・成果物: 横型動画 2分程度 1本(字幕あり)、縦型ショート 30秒 2本

■ 日程・納品
・初稿: 2026年10月31日
・納品期日: 2026年11月15日
・納品方法: 指定の共有フォルダへアップロード
・検査完了日: 納品から7日以内

■ 報酬・支払い
・報酬額: 300,000円(税抜・消費税は別途)
・支払期日: 2026年12月20日
・支払方法: 銀行振込(振込手数料は当社負担)
・経費: 報酬に含む(遠方撮影の交通費は実費を別途精算)

■ 修正・権利など
・修正: 2回まで(3回目以降は別途お見積り)。構成の大きな変更は含まない
・著作権: 報酬の支払いをもって当社に譲渡
・制作実績としての公開: 公開日以降であれば可

ご不明な点があれば遠慮なくお知らせください。
よろしくお願いいたします。
```

## 発注書を毎回作るのが大変になってきたら

発注の数が増えてきたら、テンプレートを表計算ソフトやドキュメントで管理するか、電子契約サービスで送って相手の承諾まで記録する方法があります。
どの段階でツールを入れるべきかは、ツール比較のカテゴリで整理していきます。
