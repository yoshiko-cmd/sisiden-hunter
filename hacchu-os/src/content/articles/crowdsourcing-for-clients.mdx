## まず「募集型」か「出品型」かを決める

クラウドソーシングやスキルマーケットには、発注の仕方が大きく2種類あります。

| | 募集型 | 出品型 |
|---|---|---|
| 流れ | 発注者が仕事を募集 → 応募者から選ぶ | 受注者が出品したサービスから選んで購入 |
| 向いている仕事 | 内容が具体的に決まっていて、自社専用のもの | ロゴ・バナー・簡単な編集など、内容が定型に近いもの |
| 相手の選び方 | 応募者の提案・実績・見積を見て選ぶ | 出品内容・価格・評価を見て選ぶ |
| 発注者の手間 | 募集文を書く、応募者を比べる | 出品を探して比べる |
| 注意点 | 募集文があいまいだと、比べにくい応募が集まる | 出品内容に含まれない作業は追加料金になりやすい |

主なサービスの例として、<OfferLink id="crowdworks" />や<OfferLink id="lancers" />は募集型の仕組みを中心にしており、<OfferLink id="coconala" />は出品型のスキルマーケットとして知られています(いずれも複数の頼み方を用意しているため、詳細は各公式サイトで確認してください)。

## 比べるときの観点

| 観点 | 確認すること | なぜ大事か |
|---|---|---|
| 発注者側の費用 | 発注者に手数料がかかるか、料率はいくらか | 同じ報酬でも総額が変わる |
| 支払いの仕組み | 報酬をサービスに先に預ける仕組み(仮払い)の流れ。ランサーズ・クラウドワークス・ココナラはいずれも、代金をサービスが預かり、完了後に受注者へ支払われる仕組みを案内しています | 納品されないまま支払うリスクを減らせる。検収(確認)の期限も確認しておく |
| 契約・明示の画面 | 業務内容・報酬・納期をサービス上で記録できるか | 取引条件の明示と、後からの確認に使える |
| 得意な職種 | 自社が頼みたい職種の人が多いか | 応募・出品の数と質に直結する |
| 継続依頼のしやすさ | 同じ人に続けて頼む仕組みがあるか | 相性の良い人が見つかった後に大事 |
| 請求書・インボイス | 請求書の発行や、インボイスへの対応がどうなっているか | 経理処理で困らないか |

<Callout type="note" title="料金を載せていない理由">
  <p>手数料や決済の条件は改定されることがあり、確認できていない数字を載せると読者の判断を誤らせるためです。公式の料金ページで確認した値だけを、確認日と一緒に掲載する方針です(<a href="/policy/editorial/">編集方針</a>)。</p>
</Callout>

## 良い相手に出会う募集文の書き方

募集型では、募集文の具体さが、集まる応募の質をほぼ決めます。最低限、次を書きます。

1. 目的と、見てもらう相手
2. 成果物の形(種類・長さ・点数・納品形式)
3. 納期と、途中の確認日
4. 報酬(または予算の上限)
5. 修正の回数と範囲
6. 応募時に出してほしいもの(近い実績、進め方、質問など)

「応募時に、この仕事について質問があれば書いてください」と一文入れておくと、応募文の質問の中身で、相手の考え方が分かります([面談の質問リスト](/articles/interview-questions/))。

## クラウドソーシングが向いていないとき

- 会社の顔になる大きな仕事で、進行管理まで任せたい → [制作会社とフリーランスの使い分け](/articles/company-vs-freelance/)
- 長期間、チームの一員として動いてほしい → エージェントや直接契約も検討
