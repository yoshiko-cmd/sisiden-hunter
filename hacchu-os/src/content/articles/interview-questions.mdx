## 面談の前に、こちらが準備すること

面談は、相手を見極める場であると同時に、**相手がこちらを見極める場**でもあります。依頼内容があいまいなまま面談すると、良い人ほど「この発注者は大変そうだ」と感じて離れていきます。

面談の前に、次の4つを1枚にまとめて、できれば事前に送っておきましょう。

1. 何のために作るのか(目的)
2. 誰に見てもらうのか
3. いつまでに、どのくらいの予算で
4. 社内で最終OKを出すのは誰か

[発注内容整理ジェネレーター](/tools/brief-generator/)を使うと、この内容をそのまま文章にできます。

## 質問リスト

### A. 仕事の進め方

| 質問 | 良い答えの例 | 注意したい答えの例 |
|---|---|---|
| この依頼を聞いて、まず確認したいことはありますか? | 目的・見る人・使う場所について質問が返ってくる | 質問がなく「大丈夫です、できます」だけ |
| 最初の打ち合わせから納品まで、どう進めますか? | 段階ごとに、こちらが何をいつ確認するかまで説明できる | 「お任せください」で段取りが見えない |
| 修正はどう受けていますか? | 回数や範囲について、自分からルールを提案してくる | 「何回でも」と言う(後で疲弊しやすい) |
| 連絡はどの方法で、どのくらいで返していますか? | 返信の目安や、返せない時間帯を具体的に言える | 答えがあいまい |

### B. 実績

| 質問 | 見るポイント |
|---|---|
| この作品で、あなたが担当したのはどの部分ですか? | チームで作った作品の場合、本人の担当範囲が分かる |
| この仕事で、発注者から最初にどんな依頼がありましたか? | 依頼をどう形にしたか。目的から考えられる人か |
| うまくいかなかった仕事と、そのときの対応を教えてください | 失敗を具体的に話せる人は、トラブルのときも報告してくれることが多い |
| 今回に一番近い仕事はどれですか? | 近い実績がない場合、どう補うかを説明できるか |

### C. お金と日程

| 質問 | 見るポイント |
|---|---|
| この内容だと、見積はどのくらいになりそうですか?その内訳は? | 金額の理由を説明できるか。何を削れば安くなるかも言えるか |
| 今、どのくらい他の仕事を抱えていますか? | 納期に対して無理がないか |
| この納期は現実的ですか? | 無理なら、根拠のある代案を出してくれるか |
| 請求書の発行や、インボイスの登録はどうされていますか? | 支払い手続きで困らないか(経理の確認用) |

### D. 相性

| 質問 | 見るポイント |
|---|---|
| どんな発注者だと仕事がしやすいですか? | 相手の働き方と、自社の進め方が合うか |
| 逆に、やりにくかった発注者はどんなタイプでしたか? | 自社が当てはまっていないか |
| 私たちに聞いておきたいことはありますか? | 質問の中身に、仕事への向き合い方が出る |

## 面談のあとにすること

1. **その日のうちに採点する**。時間がたつと、印象の強かった人に引っ張られます。
2. 合計点が近い候補者が複数いるときは、**小さな有償の仕事(トライアル)**を頼んで比べる。
3. 断る相手にも、期限までに連絡する。今回は合わなくても、別の仕事で頼むことがあります。
