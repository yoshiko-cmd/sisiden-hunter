## 修正指示は4点を1行で

動画の修正が何往復もするのは、たいてい指示が「どこの話か分からない」「どう直せばいいか分からない」ためです。1つの修正を、次の4点で1行にします。

| 時間 | 場所 | 直してほしいこと | 理由 |
|---|---|---|---|
| 0:12〜0:18 | 下のテロップ | 「代表取締役」→「代表取締役社長」 | 正式な役職名のため |
| 0:45 | 映像 | 社員の顔が暗いので明るく | 表情が伝わるようにしたい |
| 1:10〜1:25 | BGM | 音量を下げる | インタビューの声が聞き取りにくい |
| 1:40 | カット | このカットを削除 | 社外秘の資料が写っている |

**理由**を書くのがポイントです。理由が分かると、制作者は指示どおりに直すだけでなく、同じ理由で直すべき他の箇所にも気づいてくれます。

## 社内の意見はまとめてから送る

1. 初稿は、**最終OKを出す人にも**見てもらう(最後に方向性がひっくり返るのを防ぐ)
2. 社内の意見を**1つのリスト**に集める
3. 矛盾する意見(「テンポを速く」と「ゆっくり見せたい」など)は、社内で決めてから送る
4. まとめ役が**1回で**送り、「以上で全部です」と書く

## 伝わりにくい指示の言い換え

| 伝わりにくい | 伝わる |
|---|---|
| なんとなく違う | 採用向けなので、もう少し明るく親しみやすい雰囲気にしたい。特に0:00〜0:20の音楽 |
| もっとかっこよく | 参考動画(URL)の0:30あたりのような、テンポの速い切り替えにしたい |
| 全体的に長い | 2分以内にしたい。1:00〜1:40のインタビューは要点だけ残して短くしてほしい |
| 色が気になる | 会社のロゴの緑と合わせたい。全体の色味をもう少し落ち着かせてほしい |

「なんとなく」と感じたときは、**目的と見てもらう相手**(ブリーフに書いたこと)に照らして、どこがずれているのかを言葉にします([ブリーフの書き方](/articles/brief-template/))。

## コピーして使える修正指示シート

```text
【修正指示】(業務名) 初稿 / 第◯回修正

No. | 時間 | 場所 | 直してほしいこと | 理由
1   |      |      |                  |
2   |      |      |                  |
3   |      |      |                  |

・以上で全部です。
・判断に迷う点は、作業前にご質問ください。
・次回の確認日: ◯月◯日
```
