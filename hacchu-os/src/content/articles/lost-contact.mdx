## 連絡が途絶える理由

連絡が途絶えるのは、必ずしも相手に悪意があるからではありません。よくある背景は次のようなものです。

| 背景 | 発注者から見えるサイン |
|---|---|
| 仕事を抱えすぎている | 返信が少しずつ遅くなる、「確認します」のまま止まる |
| 遅れを言い出しにくい | 途中の報告がなくなる |
| 依頼内容が分かりにくい | 質問が来ないまま、作業も進まない |
| 体調・家庭の事情 | 急に返信が止まる |
| 条件への不満 | 修正依頼の後から返信が遅くなる |

## 発注時にできる予防

1. **連絡手段を1つに決める**(メール、チャットなど)。複数に分かれると、見落としが起きます。
2. **返信の目安を決める**(例: 平日◯営業日以内)。お互いの休みの日も伝えておく。
3. **途中の確認日を決める**。最終納期までの間に、進み具合を確認する日を入れる([納期遅れの対応](/articles/late-delivery/))。
4. **連絡が取れない場合の扱いを決めておく**。どのくらい連絡が取れなければ、どう扱うか(途中までの成果物の受け渡し、報酬の精算)を、発注時に一文入れておく。
5. **面談で、今の仕事量を聞く**([面談の質問リスト](/articles/interview-questions/))。

## 途絶えたときの手順

| 段階 | やること |
|---|---|
| 1. 普段の手段でもう一度 | 責めずに、状況だけを確認する短い連絡を送る |
| 2. 別の手段で | メールとチャットなど、登録されている別の連絡先にも送る。期限(例: ◯日まで)を書く |
| 3. 記録を残す | いつ、どの手段で、何を送ったかを記録しておく |
| 4. 代わりの手配を始める | 公開日から逆算して、別の人に頼む準備を始める |
| 5. 書面で伝える | 期限までに返信がなければ、契約を終える意思と、途中までの成果物・報酬の扱いを書面で伝える |

### 2段階目の文面例

```text
◯◯ 様

△△の□□です。先日お送りした「(業務名)」の件で、ご連絡が取れず心配しております。
お忙しいところ恐縮ですが、◯月◯日までに、状況だけでもお知らせいただけますでしょうか。

・体調やご事情で難しい場合は、その旨だけでも構いません
・途中までのデータがあれば、共有いただけると助かります

ご連絡をお待ちしております。
```
