## ブリーフは「目的」から書く

外注がうまくいかない原因の多くは、発注者の頭の中にあるイメージが、外注先に伝わっていないことです。
ブリーフは、そのイメージを伝えるための1枚です。書く順番は次のとおりです。

1. **目的** — なぜ作るのか。作ったあと、何が変わってほしいのか
2. **見てもらう相手** — 誰に届けたいのか
3. **成果物** — 何を、どんな形で
4. **使う場所** — どこで、どう使うのか
5. **日程と予算**
6. **決まっていること・決まっていないこと**

## 項目ごとの書き方

| 項目 | 悪い例 | 良い例 |
|---|---|---|
| 目的 | 会社紹介動画を作りたい | 採用の説明会で流し、応募前に職場の雰囲気を知ってもらって、入社後のミスマッチを減らしたい |
| 見てもらう相手 | 若い人 | 地元で就職先を探している20代。当社のことはほとんど知らない |
| 成果物 | かっこいい動画 | 横型2分程度1本。社員3人のインタビューと職場の様子。字幕あり |
| 使う場所 | Web | 採用サイトのトップ、説明会のスクリーン、SNS(縦型に切り出したい) |
| 日程 | できるだけ早く | 説明会が11月20日。11月10日までに最終版がほしい |
| 予算 | 相談 | 上限50万円(税抜)。超える場合は削れる部分を相談したい |
| 決まっていないこと | (書いていない) | 撮影する社員は未定。社内で10月中に決める |

「決まっていないこと」を書いておくと、外注先はそこを前提に見積や日程を組んでくれます。隠すより、書いた方が早く進みます。

## コピーして使えるテンプレート

```text
【制作依頼の概要】

1. 目的
  (何のために作るか。作ったあと、何が変わってほしいか)

2. 見てもらう相手
  (誰に届けたいか。その人は当社のことをどのくらい知っているか)

3. 成果物
  ・種類:
  ・長さ・サイズ・点数:
  ・納品形式:

4. 使う場所
  (Web、SNS、イベント、印刷物など)

5. 参考にしたいもの・避けたいもの
  (参考のURLや資料。「こういう雰囲気は避けたい」も)

6. 日程
  ・公開日/使う日:
  ・最終納品の希望日:

7. 予算
  ・上限:  円(税抜/税込)

8. 当社で用意できるもの
  (素材、出演者の調整、撮影場所など)

9. 決まっていないこと

10. 社内の確認体制
  ・担当:
  ・最終OKを出す人:
```

## ブリーフを送ったあと

- 外注先から質問が来たら、良いサインです。質問に答えることで、ブリーフの抜けが埋まります。
- 何人かに見積を頼むときは、**全員に同じブリーフ**を送ります。条件がそろうと、見積を比べられます([見積書の比べ方](/articles/quote-comparison/))。
- 条件が決まったら、発注メールで正式に依頼します([発注書に必要な項目](/articles/purchase-order-items/))。
